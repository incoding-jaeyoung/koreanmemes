# [vfmania] 캐릭터 공략 컴포넌트 제작 가이드 (공통 템플릿)

본 문서는 vfmania 커뮤니티에서 여러 캐릭터의 공략 페이지를 효율적으로 생성하기 위한 재사용 가능한 컴포넌트 구조 설계 사양서입니다. 에이전트(AI)는 이 가이드를 따라 모듈화된 코드를 작성해야 합니다.

## 1. 프로젝트 개요

- **목표**: 캐릭터 데이터(JSON)를 주입받아 동일한 UI와 기능을 출력하는 범용 캐릭터 공략 컴포넌트 제작.
- **핵심 가치**: 유지보수성 최적화, 데이터 기반 렌더링, 중복 코드 최소화.
- **프로토타입**: 본 페이지는 **프로토타입**으로 제작되며, 추후 디자인 및 기능 확장을 고려해야 합니다.

## 2. 데이터 구조 (Character Data Schema)

모든 캐릭터는 아래와 같은 표준화된 JSON 형식을 따릅니다.

```json
{
  "characterName": "Akira Yuki",
  "videoId": "t2uibcFv-9I",
  "moves": [
    { "name": "Chusui (충추)", "command": "P+G", "start": 6, "end": 8 },
    { "name": "철산고 (Tetsuzankou)", "command": "←→→ P+K", "start": 121, "end": 124 },
    { "name": "백호쌍장타 (Byakko Soushouda)", "command": "↓↙←→ P", "start": 105, "end": 108 }
  ]
}
```

## 3. 레이아웃 및 디자인 (Layout & Design)

본 페이지는 다음과 같은 레이아웃 구조를 따릅니다.

1.  **상단 (Video Player)**: 유튜브 영상 플레이어가 하나 존재하며, 특정 기술 선택 시 해당 구간을 반복 재생합니다.
2.  **하단 (Move List Table)**: 각 기술의 정보가 담긴 테이블이 위치합니다.
    -   **컬럼 구성**: 커맨드 (Command), 기술명 (Move Name)
    -   **인터랙션**: 커맨드 리스트 옆에 **[Play] 버튼**을 배치하여, 클릭 시 상단 플레이어에서 해당 기술의 영상 구간이 재생되도록 합니다.

> **참고 레퍼런스**: [아키라 기술표 예시](https://virtua-fighter.com/revo/kr/character/skill/skill01.html)
> (위 페이지의 커맨드 리스트 옆 영상 플레이 버튼 동작을 참고)

## 4. 컴포넌트 설계 (Component Architecture)

에이전트는 코드를 다음 세 가지 주요 컴포넌트로 분리하여 구현해야 합니다.

### A. MovePlayer 컴포넌트

- **역할**: 유튜브 플레이어 렌더링 및 구간 반복 로직 담당.
- **Props**: `videoId`, `activeMove` (현재 선택된 기술의 start/end 정보).
- **로직**: `useEffect`를 통해 `activeMove`가 변경될 때마다 플레이어의 시간을 감시하고, `end` 도달 시 `start`로 루프시킨다.

### B. MoveList 컴포넌트

- **역할**: 캐릭터의 전체 기술 리스트 출력 (테이블 형태).
- **Props**: `moves` (기술 배열), `onPlay` (재생 버튼 클릭 핸들러).
- **UI**:
    -   테이블 형태로 구현.
    -   각 행(Row)에 **커맨드**, **기술명**, **재생 버튼**을 포함.
    -   재생 버튼 클릭 시 `onPlay(move)`를 호출.

### C. CharacterGuidePage (Main Container)

- **역할**: 특정 캐릭터의 JSON 데이터를 불러와 `MovePlayer`와 `MoveList`를 조합.
- **상태 관리**: `selectedMove` 상태를 통해 현재 재생 중인 기술을 하이라이트하고 플레이어에 전달.

## 5. 기술적 요구 사항

1. **유연한 데이터 주입**: 캐릭터 ID나 이름을 경로(Path)나 Props로 받아 해당 캐릭터의 JSON 데이터를 동적으로 매핑한다.
2. **구간 반복 정밀도**:
   - 유튜브 API의 `onStateChange`와 `requestAnimationFrame` 또는 `setInterval`을 조합하여 루프 지연을 최소화한다.
3. **반응형 스타일링 (Tailwind CSS)**:
   - **Desktop**: 2컬럼 레이아웃 (플레이어 좌측 고정, 리스트 우측 스크롤) 또는 상단 플레이어/하단 리스트 (User Choice).
     - *프로토타입 정의에 따라 상단 플레이어/하단 리스트 구조 채택.*
   - **Mobile**: 플레이어 상단 Sticky 고정, 하단 리스트 스크롤.

이 페이지는 프로토타입이며, 상단에 유튜브 영상 플레이어, 하단에 기술표(테이블)가 위치하는 구조야.
