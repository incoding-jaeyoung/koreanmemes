# VFMANIA 추가 기능 제안서

> 현재 사이트 분석 결과를 바탕으로, 다른 커뮤니티 사이트(Reddit, 루리웹, DC인사이드, EventHubs, Dustloop 등)와 비교하여 추가할만한 기능을 우선순위별로 정리

---

## 🔴 즉시 추가 가능 (난이도 낮음, 효과 높음)

### 1. 🔔 알림 시스템 (Notifications)
> 모든 커뮤니티 사이트의 핵심. 현재 사이트에 없음

- 내 글에 댓글/좋아요 달렸을 때
- 내 댓글에 답글 달렸을 때
- 헤더에 🔔 벨 아이콘 + 읽지 않은 알림 수 뱃지
- Supabase Realtime 또는 폴링으로 구현 가능

### 2. 🔖 북마크/스크랩
> 루리웹, 디시, Reddit 전부 있음

- 게시글 옆 ⭐ 북마크 버튼
- 마이페이지에 "스크랩한 글" 탭 추가
- DB: `bookmarks` 테이블 (user_id, post_id) 하나면 끝

### 3. 📊 인기글 위젯 개선 — 기간별 필터
> 현재 좋아요 기반 전체 기간 Top 5만 있음

- **오늘/이번주/이번달** 인기글 탭 추가
- 조회수+좋아요+댓글 가중치 점수 기반 핫 랭킹
- Reddit의 Hot/Top/New 같은 정렬 옵션

### 4. 🏷️ 태그 시스템
> 게시글에 태그 추가 (예: `#아키라`, `#콤보`, `#초보질문`)

- 태그 클릭 시 해당 태그 게시글 모아보기
- 인기 태그 클라우드 위젯 (사이드바)
- 현재 카테고리 시스템과 보완적으로 사용

### 5. 📌 최근 본 글 기록
> 디시, 루리웹 등에서 기본 제공

- localStorage 기반으로 최근 본 게시글 10개 저장
- 사이드바 위젯 또는 마이페이지 탭
- 서버 저장 불필요, 프론트만으로 구현 가능

## 🟠 중간 난이도 (1-2일 작업, 효과 큼)

### 6. ✉️ 쪽지/DM (Direct Message)
> 유저 간 1:1 소통 — 격투게임 커뮤니티에서 대전 상대 구할 때 필수

- 프로필 페이지에 "쪽지 보내기" 버튼
- 받은/보낸 쪽지함
- 헤더 알림과 연동

### 7. 👤 유저 온라인 상태 표시
> Discord 스타일

- 온라인/오프라인 표시 (마지막 접속 시간 기반)
- 현재 `LocationUpdater`로 접속 감지가 이미 있으니 확장 가능
- 게시글/댓글 작성자 옆에 초록 점 표시

### 8. 📈 내 활동 타임라인
> GitHub Contribution 그래프 스타일

- 프로필에 최근 30일 활동 히트맵 (게시글/댓글/좋아요)
- 일별 활동량 시각화
- 연속 활동일수(스트릭) 표시

### 9. 🗳️ 투표/설문 기능
> 커뮤니티 의견 수렴용 — Reddit 스타일 Poll

- 게시글 작성 시 "투표 추가" 옵션
- "최강 캐릭터 투표", "시즌 티어표 투표" 등
- 결과 실시간 바 차트 표시

### 10. 🎯 대전 상대 구하기 (LFG 위젯)
> 격투게임 커뮤니티 특화 기능

- 홈 사이드바에 "대전 상대 찾기" 위젯
- PSN/Steam ID + 랭크 + 지역 표시
- "매칭 가능" 상태 토글
- 이미 게임 계정 필드가 있어서 연동하기 좋음

---

## 🟡 중장기 (3일+ 작업, 차별화 기능)

### 11. 💬 실시간 채팅방
> Twitch 채팅 / 디스코드 스타일

- 캐릭터별 or 글로벌 채팅방
- Supabase Realtime으로 구현 가능
- 토너먼트 시청 중 실시간 반응용

### 12. 🏆 포인트 & 업적 시스템
> Stack Overflow, Reddit 카르마 스타일

- 게시글 작성 +10, 댓글 +5, 좋아요 받기 +3
- 레벨업 시스템 (뉴비 → 레귤러 → 고수 → 전설)
- 특별 업적 뱃지 (첫 글, 100글, 인기글 등)
- 닉네임 옆에 레벨/뱃지 표시

### 13. 📅 이벤트/토너먼트 캘린더
> EventHubs, Start.gg 스타일

- 대회 일정 달력 위젯
- 참가 신청 기능
- 결과 기록 및 하이라이트

### 14. 📋 캐릭터 티어표 (커뮤니티 투표)
> EventHubs의 대표 기능

- 시즌별 캐릭터 강도 투표
- 실시간 티어 변동 그래프
- 랭크별 가중치 (고랭크 유저 투표 더 반영)
