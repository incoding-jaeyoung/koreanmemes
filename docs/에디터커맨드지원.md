# 기술명 자동 커맨드 표시 기능 구현 계획

## 개요
에디터에서 기술명을 정확히 입력했을 때, 자동으로 옆에 커맨드를 이미지로 표시하는 기능

## 요구사항
- **모든 게시판에서 작동**: 자유게시판, 캐릭터 게시판, 뉴스 등 모든 게시판에서 사용 가능
- **모든 캐릭터 지원**: 19명의 모든 캐릭터 기술명 지원
- **정확 매칭**: 기술명을 정확히 입력했을 때만 작동 (자동완성 없음)
- **다중 캐릭터**: 한 게시물에 여러 캐릭터의 기술명이 섞여 있어도 작동
- **커맨드 시각화**: move-list 페이지처럼 커맨드를 이미지로 표시 (화살표 + 버튼 아이콘)

## 예시
```
입력: "안장정주 "
결과: "안장정주 [→ P ← P 이미지로 표시] "

입력: "충추를 사용했다"
결과: "충추 [P 이미지로 표시]를 사용했다"

※ 커맨드 문자열("6 P 4 P P")을 CommandRenderer 컴포넌트로 화살표와 버튼 아이콘으로 시각화
```

## 기술 스택
- **에디터**: Tiptap
- **커맨드 렌더링**: 기존 `CommandRenderer` 컴포넌트 재사용
- **데이터 소스**: `/src/data/characters/*.ts` 파일들

## 커맨드 변환 로직 (기존 구현 참고)

### CommandRenderer 컴포넌트 (`/src/components/character/CommandRenderer.tsx`)

**동작 방식**:
1. 커맨드 문자열을 `splitCommand()` 함수로 토큰 분리
   - 예: `"6 P 4 P P"` → `['6', 'P', '4', 'P', 'P']`
2. 각 토큰을 확인하여 이미지로 변환
   - **방향키**: `1`, `2`, `3`, `4`, `6`, `7`, `8`, `9` → `/images/ico/{숫자}.svg`
   - **버튼**: `P`, `K`, `G` → `/images/ico/{P|K|G}.svg`
   - **홀드**: `hold2` → `/images/ico/hold2.svg`
   - **기타**: `+`, 공백, 괄호 등은 텍스트로 표시

**이미지 경로**:
- `/images/ico/1.svg` ~ `/images/ico/9.svg` (방향키)
- `/images/ico/P.svg`, `/images/ico/K.svg`, `/images/ico/G.svg` (버튼)
- `/images/ico/hold2.svg` (홀드)

**렌더링 결과**:
- 커맨드 문자열이 화살표(→←↑↓↖↗↙↘)와 버튼 아이콘(P/K/G)으로 시각화됨
- move-list 페이지(98번, 252번 라인)에서 사용 중

## 구현 단계

### 1단계: 데이터 인덱스 생성
**파일**: `/src/utils/moveCommandIndex.ts` (신규 생성)

```typescript
// 모든 캐릭터의 기술명 → 커맨드 매핑 생성
// Map<string, string> 형태로 저장
// 예: { '안장정주': '6 P 4 P P', '충추': 'P', ... }
```

**작업 내용**:
- 모든 캐릭터 데이터 파일에서 `moves` 배열 읽기
- `name` → `command` 매핑 생성
- 중복 기술명 처리 (같은 이름이 여러 캐릭터에 있을 경우)
- 초기 로딩 시 한 번만 생성 (싱글톤 또는 모듈 레벨 변수)

**예상 데이터 크기**:
- 19명 × 평균 200개 기술 = 약 3,800개 항목
- 메모리: ~30KB

### 2단계: Tiptap 커스텀 Extension 생성
**파일**: `/src/components/editor/MoveCommandExtension.ts` (신규 생성)

**기능**:
- 입력 완료 감지 (공백, 엔터, 구두점 입력 시)
- 마지막 단어가 기술명과 정확히 일치하는지 확인
- 일치하면 커스텀 노드로 교체

**InputRule 예시**:
```typescript
// 공백 입력 시 기술명 체크
InputRule({
  find: /(\S+)\s/,
  handler: ({ state, range, match }) => {
    const word = match[1];
    const command = moveCommandMap.get(word);
    if (command) {
      // 기술명 + 커맨드 노드로 교체
    }
  }
})
```

**고려사항**:
- 구두점(`,`, `.`, `!`, `?`) 입력 시에도 체크
- 한글 입력 완료 시점 감지 (IME composition end)
- 이미 변환된 노드는 다시 변환하지 않음

### 3단계: 커스텀 노드 타입 정의
**파일**: `/src/components/editor/MoveCommandExtension.ts` 내부

**노드 구조**:
```typescript
{
  type: 'moveCommand',
  attrs: {
    name: string,      // 기술명
    command: string    // 커맨드 문자열
  }
}
```

**렌더링**:
- HTML: `<span data-move-name="안장정주" data-move-command="6 P 4 P P">안장정주 [CommandRenderer로 커맨드 시각화]</span>`
- React 컴포넌트: 기술명 텍스트 + `CommandRenderer` 컴포넌트로 커맨드를 이미지(화살표+버튼)로 표시

### 4단계: TiptapEditor에 Extension 추가
**파일**: `/src/components/TiptapEditor.tsx`

**수정 내용**:
- `MoveCommandExtension` import
- `useEditor`의 `extensions` 배열에 추가

### 5단계: 데이터 파일 통합

## 성능 최적화

### 1. 데이터 구조
- **Map 사용**: O(1) 조회 성능
- **경량 데이터**: name + command만 저장 (프레임 데이터 제외)

### 2. 실행 시점
- **입력 완료 시점에만 체크**: 입력 중에는 체크하지 않음
- **정확 매칭만**: 검색 알고리즘 불필요

### 3. 메모리
- **초기 로딩**: 약 30KB (한 번만)
- **상주 메모리**: 약 30KB

## 예상 부하
- **초기 로딩**: ~30KB 데이터 로드 (한 번만)
- **메모리**: ~30KB 상주
- **검색**: Map.get() - < 1ms (O(1))
- **실행 빈도**: 사용자가 기술명 입력 완료할 때만

**결론**: 부하 매우 적음 ✅

## UI/UX 고려사항

### 변환 시점
- 입력 완료 직후 자동 변환
- 사용자가 의도하지 않은 변환 방지 (정확 매칭만)

### 되돌리기
- Ctrl+Z로 원복 가능 (Tiptap 기본 기능)

### 표시 방식
- 기술명 텍스트 + 커맨드를 이미지로 표시 (인라인)
- `CommandRenderer` 컴포넌트 사용: 커맨드 문자열("6 P 4 P P")을 화살표(→←↑↓)와 버튼 아이콘(P/K/G)으로 시각화
- move-list 페이지와 동일한 스타일
