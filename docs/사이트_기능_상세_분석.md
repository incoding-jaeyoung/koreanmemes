## 5. 🤖 AI 번역 시스템 (Translation)

| 대상 | 방식 | 모델 | 최적화 |
|------|------|------|--------|
| **게시글 제목** | 작성 시 자동 3개 언어 번역 | `gemini-2.0-flash` | DB 저장 (`post_translations`) |
| **게시글 본문** | 조회 시 온디맨드 번역 | `gemini-2.0-flash` | img/iframe → `[[BLOCK_N]]` 플레이스홀더 치환 → **토큰 절약** |
| **댓글** | 조회 시 **일괄 번역** | `gemini-2.0-flash` | 짧은 댓글 스킵, JSON 응답 포맷, 모듈 캐시 |
| **프로필 코멘트** | 프로필 저장 시 번역 | 〃 | `comment_translations` 필드 |
| 공통 | Rate Limit 429 시 자동 **재시도 (2회, 3초 간격)** | — | [gemini.ts](file:///Users/damanegi/Desktop/dev/dev-vf6/src/utils/gemini.ts) `withRetry()` |
